Sales Analysis Dashboard | Microsoft Excel

📊 Project Overview

This project focuses on analyzing sales data and transforming it into an interactive Excel dashboard to monitor key business metrics and explore sales performance.

The project involved organizing the data, performing data analysis, and using DAX measures to calculate key performance indicators (KPIs). The dashboard was developed with interactive charts, slicers, and filters to support dynamic data exploration and provide a clear view of sales performance.

📈 Key Performance Indicators (KPIs)

- Total Sales
- Total Orders
- Total Transactions
- Highest Sales by City
- Highest Sales by Representative
- Highest Sales by Region

📊 Dashboard Visualizations

- Sales by Country
- Monthly Sales Trend
- Sales by Payment Type
- Top 5 Customers
- Sales by Representative
- Sales by Origin

🎛️ Interactive Features

- Slicers & Filters: Filter and explore data by region, month, and quarter.

🛠️ Tools & Techniques

- Microsoft Excel — Data analysis and dashboard development
- Data Cleaning — Preparing and organizing the dataset
- DAX — KPI calculations and analytical measures
- Data Visualization — Presenting sales data through charts
- Slicers & Filters — Interactive data exploration

🎯 Project Objective

To transform sales data into a structured and interactive dashboard that supports performance monitoring, helps explore sales trends, and provides insights into customers, representatives, and regional sales performance.
